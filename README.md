## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Real-time Transcription** | Transcribe live audio from microphone as you speak |
| **File Import** | Supports MP3, WAV, M4A, OGG, and many other audio formats |
| **60+ Languages** | Detect and transcribe speech in over 60 languages automatically |
| **Open Source** | Free, transparent, community-maintained — no subscriptions required |
